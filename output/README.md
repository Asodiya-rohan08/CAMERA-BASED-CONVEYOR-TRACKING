# Project Outputs

This folder contains results from the project modules and pipeline.

## VEDIO11.mp4 Results
The unprefixed files were generated from the provided 1,192-frame, 466x346, 60 fps video:
- `segmentation_grid.png` - Module A segmentation comparison.
- `kalman_plot.png` - Module D tracking and simulated-dropout plot.
- `kalman_overlay.mp4` - Module D annotated tracking video.

## Synthetic Demo Results
Files prefixed with `demo_` were generated by the project's synthetic-data smoke test. They demonstrate the remaining modules and integrated pipeline; they are not measurements from `VEDIO11.mp4`:
- `demo_segmentation_grid.png` - Module A.
- `demo_undistort_before_after.png` - Module B calibration visualisation.
- `demo_optical_flow.png` - Module C.
- `demo_kalman_plot.png` and `demo_kalman_overlay.mp4` - Module D.
- `demo_eigenboxes.png` - Module E.
- `demo_pipeline_out.mp4` and `demo_pipeline_results.csv` - integrated pipeline.

Camera calibration images and labelled crops matching `VEDIO11.mp4` were not provided, so real-video size, speed-in-cm/s, recognition, and full-pipeline results are not included.
